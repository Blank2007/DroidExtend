3. FFmpeg — screen capture and hardware encoding
----------------------------------------------------------------
出处： https://ffmpeg.org/
Source: https://ffmpeg.org/
分发内容： tools/ffmpeg/bin/ffmpeg.exe
Distributed content: tools/ffmpeg/bin/ffmpeg.exe
   本机使用的是 gyan.dev 的 6.0-essentials_build 构建
   （configure 含 --enable-gpl --enable-version3）
   The build used here is gyan.dev's 6.0-essentials_build
   (its configure includes --enable-gpl --enable-version3)
许可： GPL v3（GNU General Public License version 3）
Licence: GPL v3 (GNU General Public License version 3)
用途： 用 ddagrab 抓屏、用 h264_nvenc 编码成 H.264 码流。
Purpose: capture the screen with ddagrab and encode it into an H.264 stream with h264_nvenc.
调用方式： DroidExtend 把 ffmpeg 当作**独立进程**启动，通过管道读取
   它输出的裸 H.264 字节流。本项目自己的代码没有链接 FFmpeg 的库。
How it is invoked: DroidExtend starts ffmpeg as a **separate process** and reads
   the raw H.264 byte stream it writes out, through a pipe. This project's own
   code does not link against FFmpeg's libraries.

10. 没有用到的
10. Not used
----------------------------------------------------------------
· 图标由 android/make_icon.py 用 Pillow 现画（手机端五档 mipmap 与根目录的
  DroidExtend.ico）；tools/make_icon.py 是另一份只用标准库 struct 手工写
  BITMAPINFOHEADER + BGRA 像素、只生成 DroidExtend.ico 的极简版本。
  两者都没有用任何现成素材或字体。
· The icons are drawn on the spot by android/make_icon.py with Pillow (the five
  mipmap densities plus the root DroidExtend.ico); tools/make_icon.py is a
  separate minimal version that writes BITMAPINFOHEADER + BGRA pixels by hand
  with struct and produces nothing but DroidExtend.ico. Neither uses any
  ready-made assets or fonts.
· parsec-vdd（Parsec Virtual Display Driver）只是当初调研时的候选，
  并未分发，也没有在运行时使用。
· parsec-vdd (Parsec Virtual Display Driver) was only a candidate during the initial research;
  it is not distributed and is not used at runtime.
