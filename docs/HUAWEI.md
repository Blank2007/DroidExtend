# 华为 / 鸿蒙（HarmonyOS）设备排错

**先把这份文档的底细说清楚。** 2026-10-29 有用户报告，鸿蒙 4.x 的华为设备（例：MatePad Pro）
有三个症状：① 识别不到设备；② 镜像模式点了没反应、找不到对应输出；③ 扩展模式下画面正常，
但鼠标指针不显示。**我们手上没有华为设备，下面大部分结论来自华为官方文档和公开排查帖，
不是我们在这台机器上实测出来的** —— 哪条没实测，文中都会写出来。本机（小米 16 / Android 16）
上镜像模式实测完全正常，所以问题不在镜像这套代码，而在华为 / 鸿蒙一侧的环境和系统差异。
1.8.3 这一版只增加了诊断能力 + 这份文档，没有改动任何有风险的行为。

## 一、先按顺序试这三步

### 1. 打开「仅充电时允许 ADB 调试」，USB 用途选「传输文件」

* 开发者选项里打开 **USB 调试**，并打开华为独有的那个开关 **「仅充电时允许 ADB 调试」**。
* 插上数据线后**下拉通知栏**，把 USB 用途从「仅充电」改成「传输文件 / MTP」。
* 为什么：停在「仅充电」时 adb 根本看不到这台设备 —— 调试开关开了也没用。

出处：[华为官方支持文档](https://consumer.huawei.com/uz/support/content/ru-ru00407281/)

### 2. 关掉 hdc：adb 和华为 hdc 抢同一个端口

装了 **DevEco Studio**、**华为电脑管家**、**HiSuite**，或者任何带 hdc 服务的工具，hdc 会先把设备抢走，
这时 `adb devices` 变成**空列表**（注意：不是 `unauthorized`，是一条设备都没有）。

* 退出 DevEco Studio；
* 退出华为电脑管家（托盘图标右键 → 退出）；
* 任务管理器里结束 `hdc.exe`；
* 然后重新插拔数据线，再看 `adb devices`。

adb 与 hdc 共用 **8710** 端口，这是两边会抢的地方。

出处：[华为开发者文档 FAQ](https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs-V14/faqs-performance-analysis-kit-32-0000001934976910-V14)、
[华为开发者论坛](https://developer.huawei.com/consumer/cn/forum/topic/0204155318543671213)

### 3. 关掉「纯净模式」

鸿蒙的**纯净模式**会拦截非应用市场来源的 APK。手机端 App 装不上（`adb install` 失败）
基本就是它：`设置 → 系统和更新 → 纯净模式`，关掉它，或者对本次安装单独放行。

出处：[华为开发者论坛](https://developer.huawei.com/consumer/cn/forum/topic/0214202917493369228)

## 二、症状对号入座

| 症状 | 最可能原因 | 怎么确认 | 怎么办 |
|---|---|---|---|
| `adb devices` 里一行设备都没有，程序显示“没有检测到手机” | USB 用途还停在「仅充电」，或「仅充电时允许 ADB 调试」没开 | 看手机通知栏的 USB 用途；看开发者选项里那个开关 | 照第一步改：开开关 + 改「传输文件」，重插线 |
| 插线时设备管理器里短暂出现过设备，`adb devices` 却是空的 | hdc 把设备抢走了（DevEco Studio / 华为电脑管家 / HiSuite / 任何 hdc 服务） | 插着线看任务管理器里有没有 `hdc.exe`；或看程序诊断日志里 8710 端口被谁占着 | 结束 `hdc.exe`、退出这两个程序，再重插线（第二步） |
| `adb devices` 里显示 `unauthorized` | 手机上没点「允许 USB 调试」的弹窗 | 看设备状态那一列写的就是 `unauthorized` | 手机上点允许并勾「一律允许」；弹窗一直不出现时，先去开发者选项里**撤销 USB 调试授权**，再重插线 |
| 设备能识别，但手机端 App 装不上、`adb install` 失败 | 鸿蒙「纯净模式」拦截非应用市场来源的 APK | 安装时手机有没有弹纯净模式的提示 | 关掉纯净模式，或对本次安装放行（第三步） |
| 镜像模式点「开始投屏」没反应，也找不到对应输出 | 鸿蒙对 MediaCodec / SurfaceView 的实现和 AOSP 有差异（见「已知限制」） | 换编码器、停止再开始看症状变不变 | 换 `h264`；先「停止」再「开始投屏」；仍不行就出诊断日志 |
| 扩展模式能出画面，但鼠标指针不显示 | 光标是 ffmpeg 采集时合成进画面的，没开或华为侧差异 | 设置里「显示鼠标指针」有没有勾上 | 先勾上再试；勾了仍不行 → 出诊断日志，这条我们暂时定位不了 |
| 镜像 / 扩展中途改分辨率，画面不变 | 鸿蒙的 SurfaceView 对中途改分辨率限制更严 | 改完分辨率后画面还是老分辨率 | 先「停止」再「开始投屏」，让驱动重启一遍 |
| 手机端黑屏 / 花屏（有画面但画面是坏的） | 解码器（MediaCodec）实现差异，麒麟平台需要厂商适配 | 换成 `h264` 后是否恢复 | 用 `h264` 而不是 `hevc` 再试 |

## 三、程序里怎么排查

菜单 **`工具 → 诊断连接问题…`** 会把下面这些一次打印到日志里：

* adb 版本；
* 每台被识别到的设备；
* 设备一个都没识别到时，把原始 `adb devices -l` 输出整段打出来（**空的时候这段才是关键** —— 空列表和 `unauthorized` 是两回事）；
* hdc 进程 / 8710 端口冲突；
* 华为设备的识别结果；
* 端口 27183 / 27184 的占用情况（这俩是投屏隧道用的，被别的程序占了就是“连上了但画面不来”）。

1.8.3 的诊断在检测到华为 / 鸿蒙设备时，会直接把上面第一、二、三步的提示一起打出来。

还是不行的话，**把这段日志整段贴到 [issue](https://github.com/Blank2007/DroidExtend/issues) 里**。

## 四、已知限制（老实说，这几条还没解）

### 1. 解码：HarmonyOS 对 Android MediaCodec 的实现不完全一致

麒麟平台的解码器需要厂商适配，我们不能保证每个机型上 `h264` / `hevc` 都解得出来。
**症状是手机端黑屏或花屏**（不是“没有画面”）。先换成 `h264`（别用 `hevc`）再试一次，
这能确认问题是不是出在解码器上。

### 2. 改分辨率：鸿蒙的 SurfaceView 限制更严

镜像 / 扩展时如果改了分辨率画面没变，**先「停止」，再「开始投屏」**，中间让驱动重启一遍。

### 3. 鼠标指针：扩展模式看不到指针

程序的做法是在 ffmpeg 采集时把光标合成进画面，开关是设置里的「显示鼠标指针」——
先确认这个勾上了。勾上还是看不到的话，**这一条目前无法在华为设备上复现与定位**，
麻烦点 `工具 → 诊断连接问题…` 把日志发出来。

### 4. 鸿蒙 4.x 能用，纯血鸿蒙不行

鸿蒙 4.x 仍然是 AOSP 兼容层，APK 和 adb 都能用，所以 4.x 理论上在我们的支持范围内，
属于“可以排查出来”的问题。纯血鸿蒙 NEXT / 6.0 改用 hdc、不兼容 APK，**不在支持范围**。

出处：[itying 论坛](https://bbs.itying.com/topic/6a115059c4b04d0047fcada4)

**这句话的意思是“4.x 可以试”，不是“已完全支持鸿蒙”。** 我们没有那台设备，
就没有资格说后者。

## 五、仍然不行时提供什么

贴 issue 时把这五项带上，不然只能靠猜：

1. **机型和鸿蒙版本** —— `设置 → 关于手机 / 平板`，把版本号整行抄下来（例如 `HarmonyOS 4.2.0`）。
2. **`adb devices -l` 的原始输出** —— 一行一行照抄；如果是空的，也明确写一句“空的”。
3. **`工具 → 诊断连接问题…` 打出来的整段日志** —— 别摘录，整段贴。
4. **用的哪个模式** —— 镜像还是扩展；扩展模式下是“没画面”、“有画面但没指针”，还是“指针有但画面不对”。
5. **当时的设置** —— 编码器（`h264` / `hevc`）、分辨率、刷新率、码率；数据线直插还是走扩展坞 / 转接器。
